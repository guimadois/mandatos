Como funciona

O {{ nome_site }} reúne o que os vereadores apresentam na Câmara e mostra em linguagem simples. Tudo vem de dados oficiais e cada proposição leva ao documento original.

De onde vêm os dados

Dos Dados Abertos da Câmara de Vereadores de Joinville, que publica arquivos para consulta livre. Um robô baixa esses arquivos uma vez por dia, confere se vieram completos e só então atualiza o site. Se algo vier estranho, o site continua com a última versão conferida.

De onde vêm as fotos

As fotos são as que cada vereador entregou à Justiça Eleitoral ao registrar a candidatura nas Eleições {{ tse.ano }}. Elas estão nos Dados Abertos do TSE, sob licença {{ tse.licenca }}. Não usamos fotos do site da Câmara.

Ligamos o vereador à candidatura só quando o nome é idêntico ao do TSE, entre os candidatos a vereador de Joinville. Quando o nome é diferente nas duas fontes (por exemplo, "Neto Petters" na Câmara e "Neto Petters do Novo" na urna), o vínculo foi conferido manualmente, um a um, por nome completo e partido{% if tse.manuais %}: {{ tse.manuais|join(", ") }}{% endif %}. Quem não tem correspondência aparece com as iniciais do nome, sem foto.{% if tse.com_foto < fichas|length %} Hoje, {{ tse.com_foto }} de {{ fichas|length }} vereadores têm foto.{% endif %}

O que a situação quer dizer

A situação é a etapa em que o documento está no sistema da Câmara, copiada como a Câmara publica. Ela não diz se um pedido foi atendido pela Prefeitura.

  • Pedido não é obra feita. Uma indicação é uma sugestão à Prefeitura.
  • Projeto de lei não é lei aprovada. O projeto ainda passa por comissões e votação.
  • "Arquivado" quer dizer que a tramitação do documento terminou na Câmara. Não quer dizer que foi rejeitado nem que foi atendido.

O que ainda não está aqui

  • Resumo de cada proposição (ementa): não está nos dados abertos. Vamos pedir à Câmara que inclua.
  • Busca por bairro ou rua: depende da ementa.
  • Presença nas sessões e votos: a Câmara publica, mas ainda não nos dados abertos.

Nossos compromissos

  • Só dados oficiais da Câmara, sempre com link para a fonte.
  • A mesma régua para todos os vereadores e partidos.
  • Sem nota, ranking ou opinião. Os vereadores aparecem em ordem alfabética.
  • Só informações públicas. Nenhum dado pessoal além do nome, do partido e da foto de candidatura, que a Justiça Eleitoral já publica.
  • Erros são corrigidos rápido. {% if contato_correcao %}Avise aqui.{% else %}O canal para avisar está em preparação.{% endif %}
