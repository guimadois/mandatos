Como ler estes números

  • De onde vêm os dados

    Dos arquivos de Dados Abertos da Câmara de Vereadores de Joinville. Cada proposição leva ao documento oficial.

    Fontes e data da coleta

  • Como agrupamos

    Cada proposição entra em um grupo pelo seu tipo oficial. A mesma regra vale para todos os vereadores.

    Veja a regra

  • Pedido não é obra feita

    Uma indicação é uma sugestão à Prefeitura. Os dados da Câmara não informam se o pedido foi atendido.

    Entenda as etapas

  • "Arquivado" não é rejeitado

    Quer dizer que a tramitação terminou na Câmara. Não diz se o pedido foi atendido nem se foi recusado.
